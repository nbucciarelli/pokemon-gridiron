# Pokémon Gridiron

Static site served by GitHub Pages from `main` at https://nbucciarelli.github.io/pokemon-gridiron/. No framework, no bundler, no npm.

## Layout
- `index.html`: markup only
- `css/styles.css`: all styles; colors and fonts are tokens on `:root` (single dark look by design)
- `js/app.js`: all logic in one async IIFE that fetches `data/pokedex.json` and then boots
- `data/pokedex.json` and `img/art/*.webp`: generated by `scripts/build_data.py`; don't hand-edit them

## Conventions
- Plain modern JavaScript, no dependencies. Keep it that way unless there's a strong reason.
- Paths stay relative (`data/…`, `img/…`) because the site lives under `/pokemon-gridiron/`.
- Pokédex number `n` is 1-based; `DEX[n - 1]` is its entry, `img/art/<n>.webp` its artwork.
- Generation ranges live in `GENS` in `js/app.js`. When a new generation ships, add it there and rerun `python3 scripts/build_data.py --max <new total>`.
- Anything saved in `localStorage` goes through `load()` / `save()` and must survive storage being unavailable.

## Testing
Serve locally with `python3 -m http.server 8000` and check http://localhost:8000. Run `node --check js/app.js` after editing the script.
